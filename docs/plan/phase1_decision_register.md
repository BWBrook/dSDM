# Phase 1 Decision Register

Date: 2026-06-16

This register separates implementation choices from scientific or manuscript-
material decisions. Executor-owned decisions can be made in later implementation
goals if they do not alter scientific assumptions. Barry-owned decisions must
be resolved before code paths depending on them are allowed to run.

Owner values:

- `executor`: implementation detail, provided no scientific assumption changes.
- `dSDM`: orchestration or project-scope decision.
- `Barry`: scientific, biological, data-interpretation, or manuscript-material
  decision.
