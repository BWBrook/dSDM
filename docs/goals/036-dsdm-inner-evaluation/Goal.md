# Goal 036 - Inner evaluation and method-freeze recommendation

## Objective

Turn the sealed Goal029 conventional OOF products and Goal035 six-path neural
OOF predictions into one leakage-safe, privacy-safe inner comparison for the
eight Tasmanian mammals.  The result must say what the transfer mechanisms did,
where any lift occurs along the 25/50/100% target-data curve, and which method
specification is defensible to freeze before the single outer assessment.

## Acceptance

- Validate the finalized Goal029 transaction and all current Goal035 case
  leaves without fitting or opening outer data.
- Prove exact held-row and response alignment across the two workflows in
  private memory only.
- Average frozen seed scores and apply Goal027/028's pooled-inner-OOF,
  maximum-TSS, sorted-lower-median threshold rule.
- Report all six neural paths and five conventional families for eight species,
  seven endpoints, and five spatial folds; select the best conventional family
  separately within each species and endpoint.
- Report ROC AUC and TSS as co-primary, with average precision, MCC,
  sensitivity, specificity, confusion counts, class support, threshold
  sensitivity, and seed spread as diagnostics.
- Evaluate the three frozen primary contrasts without treating rows, seeds,
  folds, or nested ladders as independent replicates.
- Publish only aggregate tables, a bounded scientific interpretation, and a
  method-freeze recommendation.  Row identifiers, labels, predictions,
  coordinates, private paths, and outer contents remain untracked.
- Independently recompute the tracked evidence; outer attempted/opened remains
  exactly `0/0`.

## Non-goals

No refitting, hyperparameter revision, architecture rescue, pseudoabsence or
reduced-predictor sensitivity, map production, outer scoring, bird work, or
manuscript rewrite belongs in Goal 036.
