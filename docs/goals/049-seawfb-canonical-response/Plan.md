# Goal 049 plan

## Stage A - count-free freeze

1. Retrieve and checksum BirdLife Working List v4.3 and Australian Bird Data
   v1 data plus metadata into the ignored Goal 049 private source directory.
2. Parse species-rank records, apply the source-field registry and role rules,
   retain every Goal 048 seed, and write a compact exception ledger.
3. Resolve each active source species to a unique current ALA species parent
   and freeze collision-free parent, descendant, and attributable-alias unions.
4. Bind the authorities, registry, taxonomy, query contract, Goal 048 domain,
   region/buffer firewall, effort rules, estimability gates, and panel policy
   into one tracked freeze receipt.
5. Stop before occurrence counts if any Stage A scientific or integrity gate
   fails.

## Stage B - aggregate acquisition and canonical substrate

1. Compare all Goal 048 active-species receipts with the Goal 049 frozen
   contract. Promote exact matches by immutable reference; do not copy or
   rewrite Goal 048 history.
2. Run a small new-species canary, validate conservation/privacy/checkpoint
   behaviour, and then launch the remaining sequential census in resumable
   `tmux` if the projected runtime is long.
3. Build a private long-form Parquet table of sorted unique species-cell
   memberships from promoted and new receipts.
4. Reconstruct distinct effort-donor richness per cell and apply focal
   exclusion separately for each target.
5. Apply the unchanged retained-training and NCP/SEH/NNC gates for `X=10`;
   calculate `X=20` availability as sensitivity only.
6. Freeze the common primary and three regional secondary panels, exclusions,
   hashes, and aggregate diagnostics.

## Review and stopping rule

Perform one focused self-review after the core validator and tests pass. Repair
material scientific, privacy, provenance, conservation, or replay defects.
Stop rather than polish if further work would only reformat receipts or add
redundant tests without changing a scientific or integrity decision.
